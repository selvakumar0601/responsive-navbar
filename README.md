# Responsive Navbar with Hamburger Menu

A modern and responsive navigation bar built using HTML, CSS, and JavaScript. The navigation menu displays horizontally on desktop screens and transforms into an animated hamburger menu on mobile devices.

## 🚀 Features

- Responsive navigation bar for desktop, tablet, and mobile.
- Animated hamburger menu icon.
- Smooth menu opening and closing transitions.
- Automatic menu closing when a navigation link is clicked.
- Keyboard accessibility with the Escape key.
- Modern UI with a clean design.
- Smooth scrolling between sections.
- Mobile-friendly layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The navigation bar uses CSS media queries to adapt to different screen sizes.

- **Desktop:** Displays all navigation links horizontally.
- **Mobile:** Displays a hamburger icon that opens a slide-down navigation menu.
- **Tablet:** Adjusts the layout according to the screen width.
